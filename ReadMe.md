# 构建文档
mdbook build

# 运行服务器

## macOS / Linux
```bash
mdbook serve --open
```

## Windows
```bash
.\mdbook.exe serve --open
```

## 安装 mdBook

### macOS
```bash
# 使用 Homebrew
brew install mdbook

# 或使用 cargo
cargo install mdbook
```

### Linux
```bash
# 使用 cargo
cargo install mdbook
```

### Windows
从 [mdBook 发布页面](https://github.com/rust-lang/mdBook/releases) 下载 `mdbook.exe`
